The original billing snapshot remains in the ignored run. This copy removes user names, user IDs and project IDs; session/model/time, token counts, effective rates and gross estimated costs are retained. Provider session events total $0.062942253, matching the recorded token estimate. This does not verify a credit deduction, invoice or balance. Storage and separate UI preview sessions are outside the total.

The initial scorer treated missing `action` as invalid for the whole pipeline response, unlike the app's existing default. The issue was discovered on validation during the run. Both models were rescored from saved raw outputs with version 2; validation still selected epoch 1, without additional held-out inference. Original snapshots/metrics are retained. Further tuning requires fresh held-out data.

To regenerate reports locally without paid inference, install optional dependencies from `backend/tinker_lab/requirements.txt`, then from the `backend` directory run:

```powershell
../.venv/Scripts/python.exe -m tinker_lab.experiment report --run-dir ../docs/tinker/run-20261025
```

Reporting does not train, sample or refresh billing, but rewrites generated reports/token accounting; keep the manifest to detect changes. Dataset preparation is deterministic: `python -m tinker_lab.experiment prepare`. For a new paid run, use a new directory and the full [protocol](../../TINKER_EXPERIMENT.md). Do not reuse this test set to tune further choices.

Checkpoints were saved with a seven-day TTL. The sampler/state paths are provenance, not a guarantee of continued remote availability or a downloadable Ollama model.
